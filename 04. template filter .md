text filter
```
{{post.title | upper}}
{{post.title | lower}}
{{post.title | capfirst}}
{{post.title | truncatechars:20}}
{{post.title | truncatewords:2}}
```
number filter
```
{{post.price | add:5}}
{{post.price | add:-5}}
{{post.price | div:5}}
{{123.4567 | floatformat:2}}   // 123.45
```
list filter
```
{{post.tags | fast}}
{{post.tags | last}}
{{post.tags | slice:2}}
{{post.tags | join:","}}
{{post.tags | length}}
```
time & date filter
```
{{post.created_at | time:"H:i"}}
{{post.created_at | date:"D:d:M:Y"}}
```
