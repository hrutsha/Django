Step 1: MySQL database বানাও
```
CREATE DATABASE mydatabase;
```
Step 2: MySQL connector install করো
```
pip install mysqlclient
```
Step 3: settings.py
```
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'mydatabase',
        'USER': 'root',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```
